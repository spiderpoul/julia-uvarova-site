# Julia Uvarova — сайт

Статический сайт https://julia-uvarova.ru/. Главная страница — index.html; вложенные страницы находятся в books/, trainings/, teambuilding/.

## Загрузка на хостинг

Необходим Python 3.9+ без дополнительных библиотек.

1. Склонируйте репозиторий или выполните `git pull origin main`.
2. Создайте локальный `.env` на основе `.env.example`: `cp .env.example .env` (Windows: `copy .env.example .env`).
3. Заполните в `.env` поля `FTP_HOST`, `FTP_USER`, `FTP_PASSWORD`, `FTP_REMOTE_DIR`. Последнее — папка корня сайта на хостинге, например `/public_html`, `/www` или `/httpdocs`. Уточните путь у провайдера.
4. Проверьте файлы без подключения: `python3 scripts/deploy_ftp.py --dry-run`.
5. Запустите загрузку: `python3 scripts/deploy_ftp.py`.

В Windows можно использовать `py` вместо `python3`.

По умолчанию `FTP_USE_TLS=true` — защищённый FTPS (explicit TLS), порт 21. Если хостинг поддерживает только обычный незашифрованный FTP, укажите `FTP_USE_TLS=false`. Режим SFTP через SSH (порт 22) не поддерживается. `FTP_PASSIVE=true` включает пассивный режим; `FTP_TIMEOUT=30` задаёт тайм-аут.

Скрипт сохраняет структуру папок, создаёт недостающие каталоги и перезаписывает одноимённые файлы на сервере. Он **не удаляет** лишние серверные файлы. Перед первой загрузкой сделайте резервную копию сайта и проверьте `FTP_REMOTE_DIR`.

## Список файлов

Публикуются HTML, CSS, JavaScript, изображения, шрифты, PDF, аудио/видео и другие статические форматы из `STATIC_EXTENSIONS` в `scripts/deploy_ftp.py`, а также `.htaccess`.

Не отправляются `.env`, `.env.example`, `AGENTS.md`, `README.md`, `.gitignore`, `.deployignore`, Python-скрипты, служебные каталоги и другие неподходящие файлы. Обязательные исключения встроены в скрипт. Настоящие реквизиты должны оставаться только в локальном `.env`, защищённом `.gitignore`.

В `.deployignore` добавляйте новые исключения по одному на строку, например `assets/drafts/`, `books/old.html`, `*.bak`. Поддерживаются шаблоны `*` и `?`, а комментарии начинаются с `#`. Правила с `!` не поддерживаются. Дополнительный ignore-list не может разрешить публикацию приватных файлов.

При ошибке `530` проверьте логин и пароль, при `550` — путь каталога и права FTP. Не путайте FTPS с SFTP.
